# 🧰 DevHub Bot

Многофункциональный Telegram-бот с инструментами для разработчиков, тестировщиков и дизайнеров. Интерфейс построен на inline-клавиатурах, Premium/Custom Emoji и отдельных графических панелях.

![DevHub Bot](Images/readme-cover.png)

## 🚀 Возможности

- форматирование и проверка JSON;
- генерация безопасных паролей;
- преобразование HEX/RGB и создание цветовых превью;
- конвертация PNG, JPG и WEBP, изменение размера и сжатие изображений;
- создание ZIP-архивов;
- генерация и распознавание QR-кодов;
- QR-коды для текста, ссылок, Wi-Fi, телефона и Telegram;
- генерация тестовых данных людей, компаний и платежных реквизитов;
- создание PNG-скриншотов кода в стиле Carbon;
- сокращение ссылок через `clck.ru`;
- преобразование PDF в изображения, сборка PDF и извлечение картинок;
- Base64 и URL encode/decode, SHA-256 и SHA-512;
- перекрашивание стикеров, emoji и пользовательских изображений;
- рендер emoji, стикеров и медиа в GIF-анимации, видео и файлы;
- настройка фона, размера, водяного знака и шрифта, история рендера.

## 🌐 Интерфейс

- русский и английский языки;
- обязательный выбор языка перед первым использованием;
- смена языка через меню или команду `/language`;
- Premium Emoji из единого каталога;
- сохранение настроек отдельно для каждого пользователя;
- редактирование существующей панели вместо цепочки сообщений.

## 🛠️ Стек

- Python `>=3.11,<3.15` (проверено на Python 3.14.7);
- aiogram 3, asyncio и FSM;
- Pillow, NumPy и OpenCV;
- PyMuPDF;
- PyAV и rlottie-python;
- Pygments, qrcode и fonttools;
- aiohttp и aiofiles.

Точные версии зависимостей закреплены в [`requirements.txt`](requirements.txt).

## ⚡ Быстрый запуск

### Требования

- CPython `>=3.11,<3.15`;
- рекомендуемая и проверенная версия — Python `3.14.7`;
- Git для клонирования проекта;
- собственный токен Telegram-бота от [@BotFather](https://t.me/BotFather);
- доступ к интернету для Telegram API и внешних сервисов.

Минимальная версия обусловлена использованием `enum.StrEnum` и зависимостями NumPy и PyAV, которым требуется Python 3.11 или новее. Полный набор тестов проверен на Python 3.14.7; остальные версии диапазона отдельно не проверялись. Файл [`.python-version`](.python-version) задаёт рекомендуемую версию, а не минимальную.

### 1. 📥 Клонирование

```bash
git clone https://github.com/shirstylee/devhub-bot.git
cd devhub-bot
```

### 2. 🐍 Виртуальное окружение

Windows PowerShell:

```powershell
py -3.14 --version
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python --version
```

Если команда `py` недоступна, используйте полный путь к установленному Python. Например, для официального Python Install Manager:

```powershell
& "$env:LOCALAPPDATA\Python\bin\python3.14.exe" -m venv .venv
```

Linux/macOS:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python --version
```

Для рекомендуемой версии проверка должна вывести `Python 3.14.7`. Если используете другую версию из поддерживаемого диапазона, замените `3.14` в команде создания окружения.

### 3. 📦 Зависимости

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m pip check
```

### 4. 🔑 Токен Telegram-бота

Создайте своего бота через [@BotFather](https://t.me/BotFather), затем скопируйте файл `.env.example` в `.env`.

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

Linux/macOS:

```bash
cp .env.example .env
```

Замените значение в `.env` настоящим токеном своего бота:

```dotenv
BOT_TOKEN=your_bot_token
```

Это единственная обязательная переменная окружения. Её также можно задать средствами хостинга без файла `.env`. Файл `.env` исключён из Git и не должен публиковаться.

### 5. ▶️ Запуск

```bash
python main.py
```

Откройте своего бота в Telegram и отправьте `/start`. Бот получает обновления через long polling; публичный веб-сервер и webhook для этого запуска не нужны. Для одного токена запускайте один экземпляр polling-процесса.

## 🤖 Команды бота

- `/start` — запуск и главное меню;
- `/menu` — открыть главное меню;
- `/language` — изменить язык интерфейса.

## ✅ Тесты

Установите зависимости и активируйте виртуальное окружение. Для тестов настоящий токен не нужен: задайте фиктивное значение, чтобы импорт конфигурации не требовал секретов.

Windows PowerShell:

```powershell
$env:BOT_TOKEN = "test-token"
python -m unittest discover -s tests -v
Remove-Item Env:BOT_TOKEN
```

Linux/macOS:

```bash
BOT_TOKEN=test-token python -m unittest discover -s tests -v
```

Тесты не запускают polling и не требуют доступа к Telegram. Удаление тестовой переменной в PowerShell позволяет следующему запуску снова прочитать токен из `.env`.

## 💾 Данные и внешние сервисы

Настройки языка и инструментов, параметры и история рендера сохраняются локально в `bot/data`. Записи привязаны к Telegram user ID; история может содержать Telegram file ID и введённый текст водяного знака. Временные файлы находятся в `bot/temp`, а загруженные шрифты — в `bot/cache/fonts`. Эти папки исключены из Git; в `data` и `temp` отслеживаются только `.gitkeep`.

Бот использует Telegram API. При сокращении ссылки её адрес передаётся `clck.ru`. При загрузке Google Font название шрифта и текст водяного знака передаются Google Fonts для подбора нужных символов. Это стоит учитывать при работе с конфиденциальными данными.

## 🔒 Безопасность и участие

- храните токен только в локальном `.env` или переменных окружения;
- не прикладывайте пользовательские файлы, базы, логи и секреты к Issues или pull requests;
- перед коммитом проверяйте `git status` и `git diff --cached`;
- если секрет попал в Git, сначала отзовите его, затем проверьте всю историю: удаление файла из последнего коммита недостаточно;
- сообщения об уязвимостях отправляйте по инструкции в [`SECURITY.md`](SECURITY.md).

Для обычных ошибок создавайте [Issue](https://github.com/shirstylee/devhub-bot/issues) с версией Python, описанием и обезличенными шагами воспроизведения. Перед pull request запускайте тесты. Ресурсоёмкую обработку пользовательских файлов на своём сервере ограничивайте по доступной памяти, CPU и дисковому пространству.
